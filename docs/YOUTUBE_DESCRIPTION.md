# Video title

OfferPilot | AI-assisted selling with seller-controlled offers and PayPal Sandbox

# Description

OfferPilot helps shoppers ask product questions, make offers within an explicit buyer budget, and complete a PayPal Sandbox purchase. Seller rules are enforced by deterministic server logic; PayPal capture status, currency, and amount are checked before an order is marked paid.

This is a sandbox demonstration using test accounts. No real payment is made.

Source and judge setup: https://github.com/Nhlanhla0001/offerpilot

Built for the PayPal AI Hackathon 2026.
